`PSNR.py` and `SSIM.py` compare adversarial PNG images with originals and aggregate scores across three configured groups. Both scripts match images by filename; missing adversarial images are skipped.

Set each `...` path to the original-image folder and the three adversarial-image folders before running the metric script. The configured groups should correspond to the experiment reported in the table.
